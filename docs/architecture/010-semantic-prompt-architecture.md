# Semantic Prompt Architecture (SPA)

## Mission

People should not have to write prompts.

People express memories, intentions, and facts through structured selections.

The system translates those selections into optimal prompts for AI.

---

## Core Principle

Human
↓
Selection UI
↓
Semantic State
↓
Prompt Translator
↓
AI Model

Prompt is generated.
Semantic State is preserved.

---

## Shared Layers

1. Selection UI
2. Semantic State
3. Domain Model
4. Prompt Translator
5. Prompt Renderer

---

## Shared Philosophy

Prompt is AI-dependent.

Semantic State is AI-independent.

The long-term asset is Semantic State.
